# 틸더스 6강 실습 페이지

JUST VUILD 2026 사전연수 6강 "내 프로그램에 날개를" 실습 페이지. 왼쪽은 교안, 오른쪽은 실습 사이트와 복사 클립보드(프롬프트·명령어).
순서는 합본 슬라이드(숨참고 Code Dive + 6강)를 따른다: 준비 → 바이브코딩 → Canvas 사례 → Canvas 1~3 → DATA → API → AI → CLI·MCP.

- 배포: https://tuilders-vibe-lab.vercel.app (GitHub 푸시 → Vercel 자동 배포)
- 정적 사이트(바닐라 HTML/CSS/JS). 탭 내용은 app.js의 TABS 배열에서 고친다.
- 설치 안내는 별도 사이트: https://tuilders-cli-setup.vercel.app
